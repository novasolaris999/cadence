# Cadence

A personal daily routine and goal tracker. See `SPEC.md` for the brief and `CLAUDE.md` for
conventions and build status.

```
npm install
npm run dev        # local dev server
npm test           # unit tests for domain rules
npm run build      # typecheck + production build (what Vercel runs)
npm run icons      # regenerate icon paths after editing scripts/gen-icons.mjs
```
